# Обученные модели GraphoMindAI

Архитектура: CNN + BiLSTM + CTC (CRNN). Код модели: `src/train.py`, класс `CRNN`.
Алфавит и размеры входного изображения сохранены внутри каждого файла `.pt`.

| Файл | Датасет | Фрагментов в обучении | Эпохи | Точность по символам | Точность по словам |
|------|---------|----------------------|-------|----------------------|--------------------|
| crnn_final.pt | Cyrillic Handwriting Dataset | 70 839 | 50 | 85,75 % | 45,06 % |
| crnn_notebooks.pt | School Notebooks (300 страниц) | 47 301 | 10 | 79,26 % | 45,12 % |

Точность измерена на тестовых выборках соответствующих датасетов. Все запуски записаны в `results.csv`.
