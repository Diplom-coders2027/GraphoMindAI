# GraphoMindAI: как всё устроено

## Что это
Веб-сервис, который распознаёт рукописный текст по фото.

## Структура проекта
- `src/app.py` — веб-интерфейс (Gradio), принимает фото и показывает текст
- `src/recognizer.py` — функция распознавания (сейчас заглушка, потом нейросеть)
- `src/dataset.py` — работа с датасетом (дописать, что именно делает)
- `docs/` — документация проекта

## Как запустить
1. Установить библиотеки: `py -3.12 -m pip install pillow gradio`
2. Запустить сайт: `py -3.12 src/app.py`
3. Открыть в браузере: http://127.0.0.1:7860

## Как это работает
Пользователь загружает фото на сайте → `app.py` передаёт его в `recognize()`
из `recognizer.py` → функция возвращает текст → сайт показывает результат.
