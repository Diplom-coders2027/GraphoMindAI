# GraphoMindAI — методичка по разработке

## 1. Назначение проекта

GraphoMindAI — веб-сервис для распознавания рукописного текста по фотографиям целых страниц.

Основная задача проекта — разработать и исследовать модели глубокого обучения, способные распознавать русский рукописный текст.

Основная архитектура нейросети — CRNN (CNN + BiLSTM + CTC).

Разработка ведётся на Python с использованием PyTorch.

## 2. Основные правила разработки

При написании кода необходимо соблюдать следующие правила:

1. Каждый Python-файл должен отвечать за определённую часть программы.
2. Не следует размещать всю логику проекта в одном файле.
3. Функции должны выполнять одну конкретную задачу.
4. Для функций желательно указывать типы входных и выходных данных.
5. Перед добавлением новых возможностей необходимо проверять работу уже написанного кода.
6. Необходимо избегать дублирования функций и ненужного усложнения программы.
7. Каждая новая часть проекта должна быть совместима с остальными модулями.
8. Изменения необходимо сохранять в Git и отправлять в GitHub.

## 3. Структура проекта

Предполагаемая структура исходного кода:

- `src/app.py` — веб-интерфейс Gradio.
- `src/recognizer.py` — основной модуль распознавания текста.
- `src/preprocessing.py` — предварительная обработка изображений.
- `src/layout.py` — анализ страницы и выделение отдельных строк.
- `src/model.py` — архитектура нейросети CRNN.
- `src/vocabulary.py` — словарь символов русского языка.
- `src/decoder.py` — преобразование предсказаний нейросети в текст.
- `src/dataset.py` — загрузка и подготовка обучающих данных.
- `src/train.py` — обучение нейросети.
- `src/metrics.py` — оценка качества распознавания.

## 4. Порядок разработки модулей

### 4.1. Предварительная обработка изображений

Файл: `preprocessing.py`

Назначение: подготовка фотографии страницы перед анализом и распознаванием.

Используемые библиотеки:

- Pillow — открытие и изменение изображений.
- OpenCV — обработка фотографий.
- NumPy — работа с массивами пикселей.

Необходимо реализовать:

1. Открытие изображения.
2. Исправление ориентации фотографии.
3. Перевод изображения в градации серого.
4. Уменьшение шума.
5. Исправление наклона текста.
6. Нормализацию изображения.
7. Подготовку изображения к поиску строк.

Результат: подготовленное изображение страницы.

### 4.2. Анализ расположения текста

Файл: `layout.py`

Назначение: поиск текстовых областей и разделение страницы на отдельные строки.

Необходимо реализовать:

1. Определение области, содержащей текст.
2. Поиск горизонтальных строк.
3. Определение границ каждой строки.
4. Вырезание отдельных строк из изображения.
5. Сохранение правильного порядка чтения.

На начальном этапе можно использовать методы обработки изображений OpenCV. В дальнейшем алгоритм можно улучшить.

Результат: набор отдельных изображений строк, подготовленных к распознаванию.

### 4.3. Создание словаря символов

Файл: `vocabulary.py`

Назначение: преобразование текстовых символов в числовые значения для нейросети.

Словарь должен содержать:

- Русские заглавные буквы.
- Русские строчные буквы.
- Буквы Ё и ё.
- Цифры.
- Знаки препинания.
- Пробел.
- Специальный пустой символ CTC.

Необходимо реализовать:

1. Создание словаря.
2. Преобразование текста в последовательность чисел.
3. Преобразование чисел обратно в текст.
4. Проверку неизвестных символов.

Результат: готовый словарь для обучения и распознавания.

### 4.4. Создание нейросети CRNN

Файл: `model.py`

Назначение: создание основной модели распознавания рукописного текста.

Архитектура состоит из трёх основных компонентов.

**CNN — Convolutional Neural Network**

Сверточная нейронная сеть извлекает визуальные признаки из изображения.

Она должна определять особенности букв, линий и других элементов рукописного текста.

**BiLSTM — Bidirectional Long Short-Term Memory**

Рекуррентная часть анализирует последовательность полученных признаков с учётом контекста в обоих направлениях.

**CTC — Connectionist Temporal Classification**

Функция потерь, позволяющая обучать модель распознавать последовательности символов без точного указания положения каждой буквы на изображении.

Необходимо реализовать:

1. Создание сверточных слоёв CNN.
2. Преобразование признаков CNN в последовательность.
3. Создание двунаправленной LSTM.
4. Выходной классификационный слой.
5. Передачу результатов в CTC Loss при обучении.

Результат: работающая архитектура CRNN.

### 4.5. Декодирование результатов

Файл: `decoder.py`

Назначение: преобразование выходных предсказаний нейросети в обычный текст.

Необходимо реализовать:

1. Получение предсказанных символов.
2. Обработку специального пустого символа CTC.
3. Удаление повторяющихся символов по правилам CTC.
4. Преобразование индексов в буквы.
5. Получение итоговой текстовой последовательности.

Результат: распознанная строка текста.

### 4.6. Работа с датасетами

Файл: `dataset.py`

Назначение: загрузка и подготовка данных для обучения нейросети.

Используемые библиотеки:

- PyTorch.
- torchvision.
- Pillow.
- NumPy.
- Pandas.

Необходимо реализовать:

1. Чтение метаданных датасета.
2. Поиск изображений и соответствующих текстовых расшифровок.
3. Проверку целостности данных.
4. Преобразование изображений в тензоры PyTorch.
5. Кодирование текстовых подписей.
6. Разделение данных на обучающую, проверочную и тестовую выборки.
7. Подготовку Batch с учётом разных размеров последовательностей.

Для основной CRNN необходимы изображения отдельных строк и соответствующие им текстовые расшифровки.

### 4.7. Обучение нейросети

Файл: `train.py`

Назначение: обучение модели CRNN на подготовленном датасете.

Используемая библиотека: PyTorch.

Необходимо реализовать:

1. Загрузку подготовленных данных.
2. Создание модели.
3. Выбор функции потерь CTC Loss.
4. Выбор оптимизатора Adam.
5. Прямое распространение данных через нейросеть.
6. Вычисление ошибки.
7. Обратное распространение ошибки.
8. Обновление весов модели.
9. Проверку модели на проверочной выборке.
10. Сохранение обученных весов.

Результат: обученная модель, готовая к использованию для распознавания.

### 4.8. Оценка качества

Файл: `metrics.py`

Назначение: оценка точности распознавания рукописного текста.

Основные метрики:

- CER (Character Error Rate) — доля ошибок на уровне отдельных символов.
- WER (Word Error Rate) — доля ошибок на уровне слов.

Необходимо реализовать вычисление обеих метрик и сохранение результатов экспериментов.

Результат: возможность сравнивать качество разных моделей и вариантов обучения.

### 4.9. Интеграция компонентов

Файлы: `recognizer.py` и `app.py`.

Назначение: объединение всех модулей в единую систему.

Последовательность работы:

1. Пользователь загружает фотографию страницы.
2. `app.py` передаёт изображение в `recognizer.py`.
3. Изображение проходит предварительную обработку.
4. `layout.py` выделяет отдельные строки.
5. CRNN распознаёт каждую строку.
6. `decoder.py` преобразует предсказания в текст.
7. Распознанные строки объединяются в правильном порядке.
8. Gradio отображает готовый текст пользователю.

Результат: полноценный веб-сервис GraphoMindAI.
