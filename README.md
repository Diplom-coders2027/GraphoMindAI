Программный комплекс для распознавания рукописного текста (Handwritten Text Recognition, HTR) с использованием методов компьютерного зрения и нейронных сетей.

## Описание проекта

GraphoMindAI — программный комплекс для распознавания рукописного текста по изображениям. В основе системы лежит нейронная сеть архитектуры CRNN, реализованная с использованием библиотеки PyTorch.

Проект включает подготовку изображений, распознавание текста и два способа взаимодействия с системой: через командную строку и веб-интерфейс.

## Установка и запуск

### 1. Получение проекта и установка зависимостей

```bash
git clone https://github.com/Diplom-coders2027/GraphoMindAI.git
cd GraphoMindAI
pip install -r requirements.txt
```

### 2. Запуск через командную строку (CLI)

```bash
python src/cli.py путь_к_изображению.jpg
```

Вместо `путь_к_изображению.jpg` указывается путь к изображению с рукописным текстом.

### 3. Запуск веб-интерфейса

```bash
python src/app.py
```

После запуска веб-интерфейс Gradio доступен по адресу:

`http://localhost:7860`

Пользователь может загрузить изображение и получить результат распознавания текста.
